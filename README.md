# QAP 1 - Advanced Programming (Java) 
#### Author: Laura Wiseman 
Semester: Third

## Objective
#### The objective of this assignment was to practice and demonstrate Object-Oriented Programming (OOP) concepts in Java, including encapsulation, constructors, getters & setters, method overloading, and class interactions. The assignment involved creating multiple classes (Account, Date, and Time) with appropriate attributes and methods, as well as writing separate test programs to validate their functionality.

### Repository contains:

#### Core Classes:
- The Account Class (Account.java) - Defines an Account class with balance management and transfer functionality.
- The Date Class (Date.java) -  Implements a Date class with day, month, and year attributes, including formatting methods.
- The Time Class (Time.java) - Represents a Time class for handling hours, minutes, and seconds.

#### Test files for each class:
- TestAccount.java - Tests the Account class, including balance checking and transfers.
- TestDate.java - Tests the Date class, ensuring correct formatting and updates.
- TestTime.java - Tests the Time class, validating time-setting and retrieval methods.

## How to Run:

1. Compile all files.
2. Run test programs individually.
